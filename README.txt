MUM FLORENCE - build the app (about 10 minutes, one time)

1. On a computer, make a free account at github.com and create a NEW repository (any name).
2. Open the repository > "Add file" > "Upload files". Drag in EVERYTHING inside this
   MumFlorence folder (including the hidden .github folder), then press "Commit changes".
   (If .github did not upload: Add file > Create new file, name it
    .github/workflows/build.yml and paste the contents of that file.)
3. Click the "Actions" tab. Wait about 5-8 minutes for "Build Mum Florence APK" to turn green.
   (If it asks, press "I understand my workflows, go ahead and enable them".)
4. Open the "Releases" section on the repository's main page, and on your phone
   download app-debug.apk. Open it and allow "install unknown apps" when asked.
5. Open Mum Florence and tap "Set up Mum Florence". Allow each thing she asks for.
   After that she listens all the time. Say "Mum Florence".
